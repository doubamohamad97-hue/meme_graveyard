# Meme Graveyard — starter website

A responsive, dark-themed static prototype for Meme Graveyard.

## Run locally
1. Install Node.js (LTS).
2. Open a terminal in this folder.
3. Run `npm install`
4. Run `npm run dev`
5. Open the local URL Vite prints.

## What's included
- Responsive landing page
- Demo grave cards and search/filter controls
- Form that validates a meme URL and opens a local preview
- Copyable grave text
- No backend, no real payments, no wallet connection, and no live market data
